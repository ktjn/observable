# Changelog

All notable changes to the `observable-contracts` component are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-07-18

Initial component baseline extracted from the `0.1.0` platform release.

### Added

- Versioned OpenAPI 3.1 contracts for the public HTTP APIs.
- Versioned event/topic contracts for the telemetry pipeline.
- Modelable `.mdl` sources compiled to committed TypeScript, Rust, and JSON Schema artifacts.
